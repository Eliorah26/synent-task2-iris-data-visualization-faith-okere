# Task 2: Iris Data Visualization

## Project Overview
This project focuses on exploring and visualizing the Iris flower dataset to understand the differences between three Iris flower species: Setosa, Versicolor, and Virginica.

The aim was to use Python visualizations to examine flower measurements, identify patterns, and compare the characteristics of the three species.

## Dataset
- **Source:** [UCI Machine Learning Repository – Iris Dataset](https://archive.ics.uci.edu/dataset/53/iris)
- **Total Records:** 150
- **Total Columns:** 5
- **Species:** Iris-setosa, Iris-versicolor, Iris-virginica
- **Features:** Sepal length, sepal width, petal length, and petal width.

## Tools and Libraries
- Python
- Google Colab
- Pandas
- Matplotlib
- Seaborn

## Project Activities
1. Loaded and inspected the Iris dataset.
2. Checked the dataset structure, data types, and missing values.
3. Examined the distribution of the three flower species.
4. Calculated descriptive statistics.
5. Created a bar chart comparing average petal length by species.
6. Created a histogram showing the distribution of sepal length.
7. Created a scatter plot showing the relationship between sepal length and petal length.
8. Compared the average measurements of the four features across the three species.

## Key Findings
- Each Iris species contains 50 records.
- The dataset contains 150 records and no missing values.
- Iris-virginica has the highest average petal length (5.552 cm).
- Iris-setosa has the lowest average petal length (1.464 cm).
- Iris-virginica also has the highest average sepal length (6.588 cm).
- Petal measurements help distinguish the three Iris species.

## Project Files
- `iris_dataset.csv` – Complete Iris dataset.
- `iris_species_comparison.csv` – Average measurements by species.
- `Synent_Task2_Iris_Data_Visualization.ipynb` – Google Colab notebook containing the analysis and visualizations.

## Conclusion
The project demonstrated how Python can be used to explore datasets, create visualizations, and identify meaningful patterns. The analysis showed clear differences in flower measurements across the three Iris species, particularly in petal length and width.
